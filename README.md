### 🚀 About Me

I am a passionate **Electronics & Communication Engineer** with a multidisciplinary focus spanning the entire technical spectrum — from **silicon-level digital logic design** and **real-time embedded robotics** to **machine learning models** and **modern software architectures**.

- 🤖 **Embedded Robotics & Control**: Architected **OmniBot**, a 3-wheeled holonomic mobile robot running on ESP32 with closed-loop PID attitude control, 9-DOF IMU (BNO08x) quaternion fusion, and real-time WebSocket telemetry.
- ⚡ **Digital Logic & Hardware Description**: Designing synthesizable digital architectures in **Verilog HDL**, including combinational data-paths (adders, multipliers, encoders) and sequential controllers (debouncers, counters, finite state machines).
- 🧠 **Applied AI & Data Science**: Building predictive pipelines, exploratory data analysis workflows, and machine learning models in Python using NumPy, Pandas, and Scikit-Learn.
- 🛠️ **Systems & Hardware Prototyping**: Experienced with ultrasonic radar systems (custom Processing GUI), sensor integration (I2C/SPI/UART), microcontroller peripherals, and C/C++ computational software.
- 🌐 **Creative Tech & Web**: Crafting responsive web applications, interactive visual tools, and creating engineering content on YouTube.
